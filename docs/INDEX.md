# Docs Index (local-only)

This folder is Sys-managed documentation stored locally on the Mac mini.

## How this is organized
- `inbox/` — quick dumps; Sys will triage into the right place.
- `reference/` — stable docs (how-tos, systems, SOPs).
- `projects/` — project-specific folders + notes.
- `logs/` — operational logs (setup notes, changes).
- `templates/` — reusable templates.

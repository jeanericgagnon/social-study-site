# Vault (full archival memory)

This is the **append-only** archive for long-form history, exports, transcripts, and reference materials.

## Structure
- `journal/` — raw daily notes, transcripts, dumps (append-only)
- `reference/` — deep reference docs
- `projects/` — project archives
- `attachments/` — PDFs/images

## Retrieval
Sys will not load this by default every session, but can search it when asked or when clearly relevant.
